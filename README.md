# ♻️ Waste Watch Campus

Waste Watch Campus is a smart waste management system designed for college campuses to improve waste monitoring, segregation awareness, and efficient waste handling using technology.

The project focuses on tracking waste data, promoting proper waste management practices, and supporting sustainability initiatives within educational institutions.

---

## 🚀 Features

- 📊 Waste monitoring and tracking
- 🏫 Campus-focused waste management system
- 🧠 Backend logic for data handling
- 🌐 Web-based interface
- 📁 Organized project structure for scalability

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python (Flask-based structure)
